# Install

`mob` is distributed as release archives and a Go module.

## With eget

```bash
eget dannyben/mob
```

## With go install

```bash
go install github.com/dannyben/mob@latest
```

## From GitHub Releases

Download the archive for your operating system and CPU from the
[Releases page](https://github.com/DannyBen/mob/releases), extract it, and put
the `mob` binary somewhere on your `PATH`.

Release archives are available for Linux and macOS on `amd64` and `arm64`.

## Uninstall

Remove the `mob` binary from the location where it was installed.
