Runpage - Interactive command pages for the terminal

Usage:
  runpage [FILE] [options] [KEY:VALUE...]
  runpage --help | -h | --version

Arguments:
  FILE
    Markdown document to open.
    When omitted, Runpage uses runpage.md and then README.md.

  KEY:VALUE
    Replace $KEY and {{ KEY }} throughout the document before rendering or
    execution. Repeat for additional values.

Document configuration:
  YAML front matter under the runpage key may declare required values,
  dependencies, and a workdir. Use --read to inspect a document without
  satisfying its value or dependency requirements.

Options:
  --show, -s
    Render the document with colors and exit.

  --read, -r
    Open the interactive reader in read-only mode. Code blocks cannot be
    selected or executed.

  --compact, -c
    Open an execution-focused interactive reader showing relevant headings and
    executable code blocks.

  --workdir DIR, -w DIR
    Run executable code blocks from DIR. Relative paths are resolved from the
    directory where Runpage was started. Use self or self/... for paths
    relative to the document's directory.

  --help, -h
    Show this help.

  --version
    Show the Runpage version.
