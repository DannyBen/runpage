Markdown Ops Book

Usage:
  mob [FILE] [options]
  mob --help | -h | --version

Arguments:
  FILE
    Markdown document to open.
    When omitted, Mob uses mob.md and then README.md.

Options:
  --show, -s
    Render the document with colors and exit.

  --read, -r
    Open the interactive reader in read-only mode. Code blocks cannot be
    selected or executed.

  --compact, -c
    Open an execution-focused interactive reader showing only executable code
    blocks with their captions.

  --help, -h
    Show this help.

  --version
    Show the Mob version.
